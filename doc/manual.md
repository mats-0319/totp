# 使用手册

这是一个符合RFC 6238标准的计算TOTP Code的应用

## 功能

本应用包含以下功能：

- 维护TOTP密钥实例（包括创建、修改、编辑）
- 计算TOTP Code

## 使用

在你第一次打开应用的时候，可以看到我们为你准备的两个示例实例，你可以通过它们来尝试几乎全部的功能。

主页面可以创建、修改密钥实例以及持续维护TOTP Code：

- 创建：点击主页悬浮按钮，会弹出创建实例对话框
- 修改：在静默状态下，实例名称将显示为一个按钮，点击按钮会弹出修改对话框
- 活动状态的实例会根据时间自动连续计算TOTP Code并显示密码的剩余有效时间

点击主页面标题栏右侧图标，可以进入应用信息页面，该页面展示了应用的基本信息，同时提供了文档页面和实例管理页面的入口：

- 应用的基本信息：包括应用图标、应用名、版本号和开发者信息
- 文档页面：包括使用手册（本文档）和技术说明
- 实例管理页面：该页面拥有实例的最高管理权限，可以随意编辑、排序、删除实例列表
    - 编辑：可以打开单个实例编辑，也可以通过导入/导出功能以文件的形式编辑
    - 排序：拖动排序
    - 删除：该页面的删除不是软删除、无法恢复

## 名词解释

1. 实例状态：一个密钥实例的状态可能是静默状态或者活动状态。
    - 静默状态：实例的准备状态，此状态下可以查看并修改实例信息。
    - 活动状态：实例的工作状态，此状态下实例开始计算TOTP Code，但是不能修改实例。
